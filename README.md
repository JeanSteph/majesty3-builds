# Majesty 3 — builds de test

Dépôt public réservé aux **builds Windows** de Majesty 3 (démonstrateur de RTS à contrôle indirect, avec un système d'IA de héros). Il ne contient aucune source : les sources du jeu et de l'IA vivent dans des dépôts privés.

Chaque version est une **Release** : télécharger le zip, décompresser, lancer `Majesty3_<version>.exe`. La note de chaque Release dit ce qui est nouveau et comment l'essayer.
